# Assignment 14: Real-Time Multiplayer Live Quiz Battle (Socket.io)

Authoritative real-time trivia quiz battle engine built with Node.js, Express, and Socket.io.

## Key Features
- **Asymmetric Roles**: Host control screen vs Mobile-friendly Player 4-color game pad.
- **PIN Room Access**: Dynamic 4-digit PIN lobby generation.
- **Server-Driven Timers**: Synchronized 15-second countdowns with server anti-cheat verification.
- **Speed Scoring**: Dynamic score formula based on answer speed (up to 1000 pts per round).
- **Live Leaderboard**: Real-time rank sorting and win-state broadcasts.
